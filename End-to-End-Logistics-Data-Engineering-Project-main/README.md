# End-to-End Logistics Data Engineering Platform

## Project Overview

An end-to-end Azure Data Engineering portfolio project demonstrating batch ingestion, medallion architecture, Delta Lake, Unity Catalog, Structured Streaming, dimensional modeling, and business-ready Databricks views.

## Medallion Architecture

### Bronze

Raw ingested datasets are landed in ADLS Gen2 and processed as Delta data.

### Silver

Business transformations and data-quality rules are applied, including:

- null handling
- duplicate removal
- timestamp normalization
- status/event normalization
- latitude/longitude validation
- schema standardization

### Gold

The project uses a star-schema model.

#### Dimensions

- `dim_customers`
- `dim_drivers`
- `dim_vehicles`
- `dim_warehouses`
- `dim_date`

#### Facts

- `fact_orders`
- `fact_shipments`
- `fact_tracking_events`

## Business Views

The final reporting layer contains only these three business views:

1. `vw_shipment_status`
2. `vw_orders_by_priority`
3. `vw_delivery_performance`

These views are intended for Databricks SQL visualization/dashboarding.

## Data Quality

The source data intentionally includes test-quality issues such as:

- missing customer city
- negative order values
- missing customer IDs
- missing driver IDs
- invalid latitude/longitude values

These are handled during the Silver transformation layer.

## Streaming

Tracking events are generated by a Python producer and published to Azure Event Hubs. Databricks Structured Streaming consumes the events through the Kafka-compatible Event Hubs endpoint and writes Delta data through the streaming Bronze/Silver layers.

The streaming data is integrated with the batch shipment/order model using `shipment_id` and the order relationship.

## Security

Secrets and credentials are intentionally excluded from this repository.

Never commit:

- Event Hubs connection strings
- SAS keys
- Azure passwords
- Databricks secrets
- storage account keys
- access tokens

Use placeholders/environment variables or a secret-management mechanism when reproducing the project.

## Project Scope

The project intentionally stops at the Databricks Gold and business-view layer.

Azure SQL reporting is **not** part of the final implementation.

The final project demonstrates:

**ADF → ADLS Gen2 → Databricks → Bronze → Silver → Gold → Business Views**

plus:

**Event Hubs → Structured Streaming → Delta**
